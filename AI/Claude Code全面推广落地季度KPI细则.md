## 一、KPI 制定核心说明

1. **适配阶段**：基于已完成账号分发、开发人员前期试用的现状，聚焦**全面规模化推广 + 体系化能力沉淀**核心阶段，跳过试点验证环节，直接对齐企业级落地的核心考核要求。
    
2. **周期设定**：完整考核周期为 1 个自然季度（13 周），分月度跟踪、季度终评两个考核节点。
    
3. **设计原则**：严格对齐领导 4 层核心诉求，100% 遵循 SMART 原则，所有指标可量化、可追溯、可核验；以「推广落地为基础、降本增效为核心、合规安全为红线、能力沉淀为长期价值」，兼顾短期 KPI 达成与长期企业 AI 能力建设。
    
4. **评级规则**：KPI 总分 100 分，加分项最高可叠加 10 分；60 分以下为不合格，60-79 分为合格，80-89 分为良好，90 分及以上为优秀。

## 三、一票否决项（触碰任意一项，季度 KPI 直接评定为不合格）

1. 发生 Claude Code 相关的代码泄露、敏感数据外泄等严重安全合规事故，造成公司损失或合规风险。
    
2. 季度末核心推广指标（账号渗透率、有效活跃率）未达 60%，且无有效改进方案。
    
3. 因强制考核、激进推广导致研发团队大面积抵触，影响正常业务交付，收到 3 个及以上团队正式投诉。
    
4. 提效数据造假、伪造使用成果，经核查确认存在弄虚作假行为。
    

## 四、超额加分项（最高可加 10 分，用于提升 KPI 评级）

1. 超额完成核心提效指标：研发交付周期缩短≥30%，或代码缺陷率降低≥25%，加 3 分。
    
2. 拓展全链路应用边界：将 Claude Code 能力成功复制到产品、运营等非研发部门，形成可落地的提效方案并验证成果，加 2 分。
    
3. 打造行业标杆案例：将落地成果整理成可对外输出的企业级案例，完成技术社区分享 / 行业峰会输出，为公司打造品牌亮点，加 3 分。
    
4. 完成企业专属 AI 能力升级：基于 Claude Code API + 公司内部知识库，通过 RAG 方案完成企业专属 AI 研发助手的原型开发与验证，加 2 分。
    

## 五、考核配套说明

1. **基准值确认**：所有对比类指标的基准值，在考核周期启动前 1 周，与领导、财务、项目管理、安全部门完成书面确认，避免考核争议。
    
2. **过程跟踪机制**：每周更新核心指标数据看板，每月向领导提交阶段性进展汇报，及时调整推广策略，确保目标按节点达成。
    
3. **资源配套对齐**：本 KPI 的达成，需同步确认配套资源（跨部门协调授权、IT / 安全 / 合规部门配合支持、培训预算等），与 KPI 细则同步报批。
