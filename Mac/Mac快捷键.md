### **Mac OS 系统快捷键完全手册**

在开始之前，我们先来认识一下 Mac 键盘上几个核心的**修饰键**，它们是所有快捷键的基础。

| 符号     | 名称                | 对应 Windows 键位 | 功能描述                            |
| :----- | :---------------- | :------------ | :------------------------------ |
| **⌘**  | **Command (Cmd)** | `Win` 键       | Mac 最核心的修饰键，绝大多数快捷键都由它组合而成。     |
| **⌥**  | **Option**        | `Alt` 键       | 用于执行备用命令，如输入特殊字符、移动/复制文件等。      |
| **⇧**  | **Shift**         | `Shift` 键     | 用于输入大写字母或执行快捷键的反向操作。            |
| **⌃**  | **Control**       | `Ctrl` 键      | 主要用于快捷键组合，或在某些应用中模拟鼠标右键。        |
| **Fn** | **Function**      | `Fn` 键        | 用于激活功能键（F1-F12）的原始功能，如调节亮度、音量等。 |

### **一、 系统级与窗口管理 (System & Window Management)**

这是最高频使用的快捷键类别，能让你轻松掌控整个操作系统。

| 快捷键 | 作用详细说明 |
| :--- | :--- |
| **`⌘ + Q`** | **退出应用程序**：彻底关闭当前应用及其所有进程，相当于 Windows 的 `Alt + F4`。这是真正的“退出”。 |
| **`⌘ + W`** | **关闭当前窗口**：仅关闭当前活动的窗口（如一个网页、一个文档），但应用程序本身仍在后台运行。 |
| **`⌘ + M`** | **最小化当前窗口**：将当前窗口最小化到程序坞（Dock）。 |
| **`⌘ + H`** | **隐藏当前应用**：将当前应用的所有窗口隐藏，使其不可见。 |
| **`⌘ + Tab`** | **切换应用程序**：在所有已打开的应用之间向前循环切换，松开按键即可切换到选中的应用。 |
| **`⌘ + Shift + Tab`** | **反向切换应用**：与 `⌘ + Tab` 相反，向后循环切换应用。 |
| **`⌘ + \``** | **切换同一应用的窗口**：在当前应用的多个窗口之间切换（` \` ` 键在数字 `1` 的左边）。 |
| **`⌘ + Option + H`** | **隐藏其他所有应用**：除了当前应用，隐藏所有其他应用的窗口，专注于当前任务。 |
| **`⌘ + Option + D`** | **显示/隐藏程序坞**：快速隐藏或显示底部的程序坞，为屏幕腾出更多空间。 |
| **`Fn + F11`** 或 **`⌘ + F3`** | **显示桌面 (Mission Control)**：将所有窗口推开，显示桌面和所有打开的窗口缩略图。 |
| **`⌘ + Control + F`** | **全屏切换**：让当前应用在全屏和窗口模式之间切换。 |
| **`⌘ + Option + Esc`** | **强制退出应用**：当应用无响应时，呼出“强制退出应用程序”窗口来结束它。 |
| **`Control + 电源键`** | **关机/重启/睡眠对话框**：呼出包含“重新启动”、“睡眠”、“关机”选项的对话框。 |
| **`Option + ⌘ + 电源键`** | **退出所有应用并睡眠**：保存所有文稿后，让 Mac 进入睡眠状态。 |
| **`Control + Command + 电源键`** | **强制重启**：在系统严重卡死时使用。 |

### **二、 文件管理 (Finder)**

在访达（Finder）中熟练使用快捷键，可以极大提升文件操作效率。

| 快捷键                               | 作用详细说明                                                                                                |
| :-------------------------------- | :---------------------------------------------------------------------------------------------------- |
| **`⌘ + N`**                       | **新建访达窗口**：打开一个新的访达窗口。                                                                                |
| **`⌘ + Shift + N`**               | **新建文件夹**：在当前位置创建一个新文件夹。                                                                              |
| **`⌘ + O`**                       | **打开所选项**：打开选中的文件或文件夹。                                                                                |
| **`⌘ + E`**                       | **推出磁盘/宗卷**：安全地弹出 U 盘、移动硬盘或光盘镜像。                                                                      |
| **`⌘ + I`**                       | **显示简介**：打开选中文件的“简介”窗口，可查看和修改文件信息（如默认打开方式）。                                                           |
| **`⌘ + Delete`**                  | **移到废纸篓**：将选中的文件或文件夹移动到废纸篓。                                                                           |
| **`⌘ + Shift + Delete`**          | **清倒废纸篓**：弹出确认对话框，清空废纸篓。                                                                              |
| **`⌘ + Option + Shift + Delete`** | **立即清倒废纸篓**：不经确认，直接清空废纸篓。                                                                             |
| **`⌘ + D`**                       | **复制文件**：在访达中，这是“复制”所选文件的快捷键（注意：不是 `⌘ + C`）。                                                          |
| **`⌘ + Option + V`**              | **移动文件 (剪切+粘贴)**：这是 Mac 上实现“剪切”文件的方式。先在原位置 `⌘ + C` 复制，然后到目标位置按 `⌘ + Option + V`，文件会被移动过来，原位置的文件会自动删除。 |
| **`⌘ + 1` / `2` / `3` / `4`**     | **切换视图模式**：分别切换为图标、列表、分栏、封面流视图。                                                                       |
| **`⌘ + Shift + G`**               | **前往文件夹**：直接输入文件夹的绝对路径，快速跳转。                                                                          |
| **`⌘ + [ ` / ` ] `**              | **返回/前进**：在访达的浏览历史中后退或前进。                                                                             |
| **`⌘ + 上箭头`**                     | **打开包含当前文件夹的文件夹**：向上一级目录。                                                                             |
| **`空格键`**                         | **快速查看 (Quick Look)**：选中文件后按空格，可快速预览文件内容，无需打开应用。                                                      |
| **`⌘ + Shift + 句点`**              | 查看当前文件夹隐藏文件                                                                                           |
|                                   |                                                                                                       |

### **三、 截图与录屏 (Screenshots & Recording)**

macOS 内置了强大的截图和录屏功能，无需安装第三方软件。

| 快捷键 | 作用详细说明 |
| :--- | :--- |
| **`⌘ + Shift + 3`** | **全屏截图**：截取整个屏幕，并将图片文件保存在桌面上。 |
| **`⌘ + Shift + 4`** | **区域截图**：光标变为十字，拖拽选择一个区域进行截图，文件保存在桌面上。 |
| **`⌘ + Shift + 4` + `空格键`** | **窗口截图**：在按下 `⌘ + Shift + 4` 后，按空格键，光标变为相机，点击任意窗口即可截取该窗口（带阴影效果），文件保存在桌面上。 |
| **`⌘ + Shift + 5`** | **截图和录屏工具栏**：呼出截图/录屏的控制面板，可以进行全屏、区域、窗口截图，以及全屏、区域录屏，还可以设置计时和保存位置。 |
| **`⌘ + Control + Shift + 3`** | **全屏截图到剪贴板**：截取整个屏幕，但图片不保存为文件，而是直接复制到剪贴板，方便粘贴。 |
| **`⌘ + Control + Shift + 4`** | **区域截图到剪贴板**：选取一个区域截图，图片直接复制到剪贴板。 |

### **四、 文本编辑 (Text Editing)**

在任何文本输入框（如备忘录、Pages、代码编辑器）中，这些快捷键都通用。

| 快捷键 | 作用详细说明 |
| :--- | :--- |
| **`⌘ + C` / `V` / `X`** | **复制 / 粘贴 / 剪切**：最基础的文本操作。 |
| **`⌘ + Z`** | **撤销**：撤销上一步操作。 |
| **`⌘ + Shift + Z`** | **重做**：恢复被撤销的操作。 |
| **`⌘ + A`** | **全选**：选中所有文本。 |
| **`⌘ + F`** | **查找**：在当前文档或页面中查找关键词。 |
| **`⌘ + S`** | **保存**：保存当前文档。 |
| **`⌘ + Option + Shift + V`** | **粘贴为纯文本**：粘贴时自动清除原文本的所有格式（如字体、颜色、链接）。 |
| **`Option + Delete`** | **删除光标前的单词**：向后删除一个完整的单词。 |
| **`Fn + Delete`** | **向前删除**：删除光标后的字符（相当于 Windows 键盘的 `Delete` 键）。 |
| **`⌘ + 左/右箭头`** | **移动光标到行首/行尾**。 |
| **`Option + 左/右箭头`** | **移动光标到上一个/下一个单词**。 |
| **`⌘ + 上/下箭头`** | **移动光标到文档开头/结尾**。 |
| **`⌘ + B`** | **加粗**所选文本。 |
| **`⌘ + I`** | **倾斜**所选文本。 |
| **`⌘ + U`** | **下划线**所选文本。 |

| 快捷键 | 作用详细说明 |

### **六、 启动与特殊功能 (Startup & Special Functions)**

这些快捷键通常在开机时或遇到系统问题时使用。

| 快捷键 (开机时按住) | 作用详细说明 |
| :--- | :--- |
| **`Option (⌥)`** | **显示启动管理器**：如果安装了双系统或有可引导的 U 盘，可以选择从哪个磁盘启动。 |
| **`⌘ + R`** | **进入恢复模式 (Recovery)**：用于重新安装 macOS、修复磁盘或从 Time Machine 备份恢复。 |
| **`⌘ + Option + P + R`** | **重置 NVRAM/PRAM**：当遇到扬声器音量、屏幕分辨率、时区等设置问题时，可以尝试重置。 |
| **`Shift`** | **安全模式启动**：以最少的系统扩展启动，用于排查软件冲突问题。 |
| **`D`** | **Apple 硬件测试**：启动硬件检测程序，检查电脑硬件是否有问题。 |
| **`C`** | **从光盘/U盘启动**：从可引导的介质（如安装盘）启动电脑。 |

### **💡 进阶技巧与建议**

1.  **自定义快捷键**：几乎所有快捷键都可以修改。进入 **系统设置 > 键盘 > 键盘快捷键**，你可以为任何应用程序的菜单命令创建或修改快捷键。
2.  **使用 CheatSheet**：这是一款非常著名的免费小工具，安装后在任何应用中**长按 `⌘` 键**，就会弹出一个当前应用所有快捷键的列表，是记忆和发现快捷键的神器。
3.  **Fn 键的妙用**：在 MacBook 上，功能键（F1-F12）默认是调节亮度、音量等。如果想使用标准的 F1-F12 功能，需要按住 `Fn` 键再按对应的功能键。你也可以在 **系统设置 > 键盘** 中设置“将 F1、F2 等键用作标准功能键”。
4.  **`Control` 键的妙用**：`# 鼠标点击` 或 `#触控板双指轻点` 通常可以模拟鼠标右键菜单。在截图快捷键中配合 `Control` 键可以将截图存入剪贴板。

希望这份详尽的手册能帮助你更高效地使用 Mac！建议先从最常用的几个（如 `⌘+C/V`, `⌘+Q/W`, `⌘+Tab`, `⌘+Shift+4`）开始记忆，逐步养成肌肉记忆。
